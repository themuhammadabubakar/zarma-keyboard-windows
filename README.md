# Zarma Keyboard
Windows support for the Zarma language using the Biiriize Hanney Alphabet (BI-H/GH) script. Includes a custom keyboard layout, system-wide character rendering, and dedicated browser tools.

Features:

- Custom keyboard layout
- Rendering support across the entire system
- Browser tools for typing and rendering

Download the latest release [Here](https://github.com/themuhammadabubakar/zarma-keyboard-windows/releases/latest).
